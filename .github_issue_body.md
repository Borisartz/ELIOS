## What was done

Migrated the BOM table from static data (`bomData.js`) to a dynamic Google Sheets API.

### Files changed
- `src/data/bomData.js` — renamed to fallback data
- `src/components/BOMTable.jsx` — full rewrite with API integration

### New features
- BOM data loads from Google Sheets in real-time
- Skeleton loading state (no spinner)
- 5-minute sessionStorage cache
- Refresh button to bypass cache
- Silent fallback if API fails
- Component column now shows specification + external link icon
- Categories derived dynamically

### Architecture
```
Google Sheets → Apps Script (JSON API) → React (fetch) → Render
```

## Known limitations

- Google Apps Script cold start: first visitor after idle may wait ~3-5 seconds
- `.env` is local only — the API URL must be set manually in Vercel dashboard
- Items with `quantity: 0` (three Baut M3 rows) still appear in table — consider hiding zero-qty rows or marking them as optional
