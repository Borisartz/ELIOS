## Overview

I'm building a web-based product showcase for the **ELIO** robotics project — a smart waste sorting robot that uses computer vision to classify and organize waste into categorized bins (organic, inorganic, and hazardous).

This website serves as the public-facing product page, featuring a landing section, a Bill of Materials (BOM), and a datasheet preview for technical reference.

---

## Features

* **Landing Page** — Clean hero section with project introduction
* **Product Showcase** — Overview of system and key functionalities
* **Bill of Materials** — Structured table of components and specifications
* **Datasheet Preview** — Preview component datasheets directly in the browser
* **Responsive Design** — Optimized for desktop and mobile
