# ELIO - Environmental Learning Intelligent Organizer

## Overview

I'm building ELIO, a robotics project designed for environmental learning. This website serves as a product showcase, introducing the robot and providing essential documentation.

## Features

- **Landing Page** – Introduction to the ELIO robot
- **BOM Table** – Complete Bill of Materials list
- **Datasheet Preview** – View and download the PDF datasheet

## Tech Stack

- React
- Vite
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
```

## Usage

Open the website in your browser to explore the ELIO robot features, view the bill of materials, and access the technical datasheet.
